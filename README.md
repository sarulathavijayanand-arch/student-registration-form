# Student Registration System

## About the Project
The Student Registration System is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to enter student details, validate the information, and register students through an easy-to-use form.

## Features
- Student registration form
- Input validation for all required fields
- Email and mobile number validation
- Date of birth validation
- Course and gender selection
- Reset button to clear the form
- Displays registered students in a table
- Success message after registration
- Responsive design for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Creates the registration form and student list.
- `style.css` – Styles the form, buttons, and table.
- `script.js` – Handles validation, registration, and reset functionality.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter the student details and click **Register**.
5. View the registered students in the table.

This project helped me practice HTML forms, CSS styling, JavaScript DOM manipulation, event handling, form validation, and dynamic table creation.
